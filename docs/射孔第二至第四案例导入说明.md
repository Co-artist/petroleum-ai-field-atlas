# 射孔第二至第四案例：手动导入

依次打开门户 `index.html`，点击「＋ 添加案例」，选择下列**整个文件夹**。看见校验结果后，可先点「试跑示范」，再由你点击「校验并添加」。每包的 `case.json`、`demo` 与 `paper` 子目录都要一起选择；不要只上传清单。

| 顺序 | 案例文件夹 | 绑定场景 | 原始论文按钮 |
| --- | --- | --- | --- |
| 1 | `case-packs/p2-tunnel-shape` | `p2` 射孔孔道形态预测 | 长度论文、孔径论文 |
| 2 | `case-packs/p3-charge-kg` | `p3` 射孔弹型智能选型 | KG4CUT、射孔弹试验论文 |
| 3 | `case-packs/p4-skin-assessment` | `p4` 射孔效果智能评估 | 总表皮系数论文 |

每次导入后，打开三个标签页；在案例演示中调整左侧至少两个参数，核对剖面、结果和方案对照是否一起变化，再点击每个「查看原始论文」按钮确认 PDF 能打开。若同一浏览器里已有同 ID 的旧案例，先在案例库移除旧版；本次三个 ID 与之前五例不同。

## 论文与教学演示的区别

- `p2` 两篇论文分别预测 API 靶试穿透长度和井下入口孔径；演示把两个标量画在同一示意剖面中，**不表示论文建立了完整三维孔道模型**。
- `p3` KG4CUT 研究铣削刀具知识图谱；本例借鉴它的目录结构化和关系查询方式。DP/BH 弹型及双层套管试验来自补充石油论文；匹配分是教学计算，不能当作真实产品指标。
- `p4` 原论文预测整井总表皮系数；多井巡检排序是明确标注的教学后续应用，不能凭整井指标定位孔段或直接决定补孔。

三个案例演示全部为前端页面，不需要服务器。浏览器上传包上限为 12 MiB；三个包均低于上限。`case-packs/SHA256SUMS-p2-p4.txt` 列出交付文件哈希。构建源文件在 `tools/build_perforation_more.py` 与 `tools/perforation_demo/`，如需改案例内容，修改源文件后运行生成器即可；无需改门户的案例导入接口。
